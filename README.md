# 角色機入門包

讓 Claude 換視窗也不失憶：視窗可以清空，記憶在檔案裡。

先打開 **簡報.pdf** 看 5 分鐘，再看 **彎路清單.md**。

## 你需要什麼
- Mac，裝好 Claude Code 或 Claude 桌面 App。Windows 還沒測過。
- 不用 GitHub 帳號，也不用會寫程式。

## 怎麼裝：zip 丟進去就裝好（約 5 分鐘）
1. 下載 zip：https://github.com/sam85510/role-machine-starter/archive/refs/heads/main.zip
2. 開一個 Claude 視窗，把 zip 拖進去，打「幫我裝角色機，叫我小明」，換成你的稱呼。
3. 它會先講會改什麼，你說好才裝。

不會蓋掉你原本的規則和設定：只在後面加一段，改之前先備份。

### 給 Claude 的安裝步驟
使用者丟 zip 進來時照做：
1. 解壓到 `~/角色機入門包`。這個資料夾已經有東西，先改名成 `~/角色機入門包.bak-日期`。
   用 `ditto -x -k <zip 路徑> <暫存資料夾>` 解壓，再把裡面的 `role-machine-starter-main` 搬成 `~/角色機入門包`。不要用 `unzip`，Mac 內建的 unzip 會把中文檔名弄壞。
2. 讀 README.md 和 安裝.sh，用白話跟使用者講會改什麼。
3. 使用者同意後跑 `bash ~/角色機入門包/安裝.sh --稱呼 "<使用者的稱呼>"`
4. 安裝最後如果列出「有選裝功能還沒判斷」：照 `選裝.txt` 每項「什麼情況才裝」判斷這台電腦和使用者的用法，看不出來就問一句。要裝的名稱寫進 `~/.claude/角色機_要裝.txt`，不裝的寫進 `~/.claude/角色機_不要裝.txt`，再跑一次安裝。
5. 跟使用者說工作資料夾在哪、選裝的裝了哪些（為什麼）、下一步做什麼。

### 會用 git 的人
`git clone https://github.com/sam85510/role-machine-starter.git ~/角色機入門包`，再跑上面第 2–4 步。之後更新比較方便。

## 裝完第一天
1. 重開 Claude，用工作資料夾（預設 `~/Claude工作室`）開一個視窗。它會先帶你開張，或者打 `/開張`，約 10 分鐘：
   - 定資料夾：照「長期要養的東西」分，看 `資料夾分類.md`。
   - 取名字：幫團隊取名，人名或職稱都可以，好記就好。一個名字可以身兼好幾項專長，先從少的開始。
2. 開張做完，它會給你一句話。開一個新視窗貼上，那是你的總入口，以後不要關。
3. 開第三個視窗，丟一件真的工作。它會建議帶誰，你點頭就開始。
4. 它做錯時直接糾正。它會先記進筆記本試著做；等事情做完、你收下了，或同一個修正在兩件不同的事都出現，才把這個做法長成那個人的規則，並告訴你一聲。

## 裝了什麼

| 東西 | 放哪 | 做什麼 |
|---|---|---|
| 工作規則 | `~/.claude/CLAUDE.md` 標記的那一段 | 回話方式、開工收工步驟 |
| 開工檢查 | `~/.claude/hooks/角色機/` | 新視窗自動讀最近 2 天日誌 |
| 收工檢查 | 同上 | 筆記太長、決定沒寫下來、有產出沒記日誌，各擋一次 |
| 標題檢查 | 同上 | 桌面 App 的視窗標題沒寫「任務名｜名字」，擋一次叫它改 |
| 講中文檢查（選裝） | 同上 | 回覆有整句英文就擋，叫它改用中文重寫 |
| 主線符號（選裝，會先問你） | 同上 | 視窗標題前面加主線 emoji 和號碼，手機上好認 |
| 開桌面視窗（選裝，會先問你） | 同上 | 用手機遠端時，讓 AI 在電腦上開新視窗 |
| 5 項專長 | 工作資料夾的 `角色/` | 總入口、審核、工程、研究必備，企劃是範例。開張時併進你取的名字 |
| 資料夾分類 | 工作資料夾的 `資料夾分類.md` | 怎麼分、要不要開新資料夾、拿不準放哪 |
| `/開張` | 指令 | 第一次定資料夾、幫團隊取名字 |
| `/收工` | 指令 | 寫好筆記和日誌，告訴你可以收視窗 |
| `/新專長 <名稱>` | 指令 | 加一項專長，給現有的人或開新名字 |
| `/收技能 <位置>` | 指令 | 丟別人的技能進來，它讀懂在做什麼，建議交給誰補強 |
| `/收` | 指令 | 只收起這個視窗（電腦和手機兩邊），不寫筆記、最省額度。只有桌面 App 能用，終端機版直接關掉就好 |

### 選裝：每台電腦自己判斷
`選裝.txt` 列的功能不一定每個人都要。安裝時 Claude 會照每項「什麼情況才裝」自己判斷；不想要某支，寫進 `~/.claude/角色機_不要裝.txt` 就不會裝。

### 選裝引導（給 Claude）
標【要先問使用者】的，用白話講好處、問他要不要；不要就寫進不要裝清單，要就照下面帶他做完，最後寫進要裝清單、再跑一次安裝。

**主線符號**
1. 問：「要不要讓每個視窗標題前面有主線的 emoji 和號碼？例『🛒3 上架新品｜小美』，手機上一眼看出是哪條線的第幾件。只有桌面 App 有用。」
2. 要的話：列出工作資料夾第一層的資料夾，幫每個配一個好認的 emoji，列給他看，他說好或改。
3. 寫進 `~/.claude/hooks/角色機/分區符號.txt`，一行「資料夾名 emoji」，例 `01客戶案 🤝`。
4. 有側邊欄工具（`mcp__ccd_sidebar__*`）就幫他開同名分區，沒有就教他在桌面 App 左邊欄自己開。
5. 之後開新視窗，用 `python3 ~/.claude/hooks/角色機/主線符號.py 下一號 <資料夾名>` 拿開頭。標題沒加會被擋一次提醒。

**開桌面視窗**
1. 問：「你會用手機遠端控制叫 AI 開新視窗嗎？手機連進來時，App 不讓 AI 直接開新視窗；裝這個，它就能在電腦上開一個，手機也看得到。」
2. 要的話：跑 `command -v claude` 確認有終端機版 Claude Code，沒有就帶他裝好。
3. 用法：`sh ~/.claude/hooks/角色機/開桌面視窗.sh "<資料夾完整路徑>"`，印出編號後依序設模型、改標題、傳交代、打開手機連線。

### 2026/11/26 更新了什麼
- 拿掉 2 支檢查：找不到要再試、互動頁要有按鈕。這兩支太看個人習慣，有時只是字面寫到就擋，反而多傳一次訊息。舊版裝過的，重跑安裝就會撤掉（程式改名留著，不刪）。

### 2026/11/17 更新了什麼
- 加 4 支檢查：標題、找不到要再試、互動頁要有按鈕、講中文（選裝）。
- 加 `/收` 指令；告一段落改建議打 /收。
- 加 2 個要先問的選裝：主線符號（標題 emoji＋號碼）、開桌面視窗（手機遠端開新視窗），安裝時 Claude 會問你要不要、帶你設定。
- 規則加：問問題的格式（分類、急不急、⑴⑵⑶）、舊題先查還成不成立、找不到先換 2 種方法、中途短句不插話、講狀態前先查實際、說「討論」先評估、大事交出去前問要不要找更強的模型看。

`~/.claude/CLAUDE.md` 和 `settings.json` 改之前都會備份成 `.bak-日期`。你原本寫的內容不會被蓋掉。

## 怎麼更新
下載新的 zip，一樣丟給 Claude 說「幫我更新角色機」。用 git 裝的，跟 Claude 說「跑 `git -C ~/角色機入門包 pull`，再跑 `bash ~/角色機入門包/安裝.sh`」。
已經長出規則的規格、筆記本、日誌都不會被蓋掉。

## 想移除
刪掉 `~/.claude/CLAUDE.md` 裡「角色機規則」那段，再刪掉 `~/.claude/settings.json` 裡指向 `hooks/角色機` 的那幾段。工作資料夾是你的，要留要刪自己決定。
