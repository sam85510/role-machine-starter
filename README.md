# 角色機入門包

讓 Claude 換視窗也不失憶：視窗可以清空，記憶在檔案裡。

先打開 **簡報.pdf** 看 5 分鐘，再看 **彎路清單.md**。

## 你需要什麼
- Mac，裝好 Claude Code 或 Claude 桌面 App。Windows 還沒測過。
- 不用 GitHub 帳號，也不用會寫程式。

## 怎麼裝：zip 丟進去就裝好（約 5 分鐘）
1. 下載 zip：https://github.com/sam85510/role-machine-starter/archive/refs/heads/main.zip
2. 開一個 Claude 視窗，把 zip 拖進去，打「幫我裝角色機，叫我小明」，換成你的稱呼。
3. 它會先講會改什麼，你說好才裝。

不會蓋掉你原本的規則和設定：只在後面加一段，改之前先備份。

### 給 Claude 的安裝步驟
使用者丟 zip 進來時照做：
1. 解壓到 `~/角色機入門包`。這個資料夾已經有東西，先改名成 `~/角色機入門包.bak-日期`。
   用 `ditto -x -k <zip 路徑> <暫存資料夾>` 解壓，再把裡面的 `role-machine-starter-main` 搬成 `~/角色機入門包`。不要用 `unzip`，Mac 內建的 unzip 會把中文檔名弄壞。
2. 讀 README.md 和 安裝.sh，用白話跟使用者講會改什麼。
3. 使用者同意後跑 `bash ~/角色機入門包/安裝.sh --稱呼 "<使用者的稱呼>"`
4. 跟使用者說工作資料夾在哪、下一步做什麼。

### 會用 git 的人
`git clone https://github.com/sam85510/role-machine-starter.git ~/角色機入門包`，再跑上面第 2–4 步。之後更新比較方便。

## 裝完第一天
1. 重開 Claude，用工作資料夾（預設 `~/Claude工作室`）開一個視窗。它會先帶你開張，或者打 `/開張`，約 10 分鐘：
   - 定資料夾：照「長期要養的東西」分，看 `資料夾分類.md`。
   - 取名字：幫團隊取名，人名或職稱都可以，好記就好。一個名字可以身兼好幾項專長，先從少的開始。
2. 開張做完，它會給你一句話。開一個新視窗貼上，那是你的總入口，以後不要關。
3. 開第三個視窗，丟一件真的工作。它會建議帶誰，你點頭就開始。
4. 它做錯時直接糾正。它會問「下次還要照做嗎？」，答「要」，規則就長進那個人身上。

## 裝了什麼

| 東西 | 放哪 | 做什麼 |
|---|---|---|
| 工作規則 | `~/.claude/CLAUDE.md` 標記的那一段 | 回話方式、開工收工步驟 |
| 開工檢查 | `~/.claude/hooks/角色機/` | 新視窗自動讀最近 2 天日誌 |
| 收工檢查 | 同上 | 筆記太長、決定沒寫下來、有產出沒記日誌，各擋一次 |
| 5 項專長 | 工作資料夾的 `角色/` | 總入口、審核、工程、研究必備，企劃是範例。開張時併進你取的名字 |
| 資料夾分類 | 工作資料夾的 `資料夾分類.md` | 怎麼分、要不要開新資料夾、拿不準放哪 |
| `/開張` | 指令 | 第一次定資料夾、幫團隊取名字 |
| `/收工` | 指令 | 寫好筆記和日誌，告訴你可以收視窗 |
| `/新專長 <名稱>` | 指令 | 加一項專長，給現有的人或開新名字 |

`~/.claude/CLAUDE.md` 和 `settings.json` 改之前都會備份成 `.bak-日期`。你原本寫的內容不會被蓋掉。

## 怎麼更新
下載新的 zip，一樣丟給 Claude 說「幫我更新角色機」。用 git 裝的，跟 Claude 說「跑 `git -C ~/角色機入門包 pull`，再跑 `bash ~/角色機入門包/安裝.sh`」。
已經長出規則的規格、筆記本、日誌都不會被蓋掉。

## 想移除
刪掉 `~/.claude/CLAUDE.md` 裡「角色機規則」那段，再刪掉 `~/.claude/settings.json` 裡指向 `hooks/角色機` 的兩段。工作資料夾是你的，要留要刪自己決定。
