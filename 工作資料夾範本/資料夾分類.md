# 資料夾怎麼分

一句話：**資料夾＝長期要養的東西。** 不按部門分，不按專長分，也不按檔案類型分。

人會換、專長會併，要養的東西不會變。按專長分，同一個客戶的東西會散在五個地方。

## 三層分清楚
- **資料夾**：長期要養的東西，例如一條產品線。
- **視窗**：一件有終點的任務。做完就收。
- **人**：有好記的叫法（人名或職稱），可以身兼好幾項專長，一個視窗可以帶好幾位。

## 這件事要不要開資料夾
- **一個視窗做得完、有終點** → 小專案。不開資料夾，筆記放進最接近的資料夾 `筆記/`，做完關視窗。
- **會同時開兩件以上，或做完還會長新任務** → 大專案。開資料夾，一件任務一個視窗，再加一本總筆記。
- **小專案長大了** → 開資料夾，把筆記本搬進去，不用重來。

## 預設分類

| 資料夾 | 放什麼 | 例子 |
|---|---|---|
| 01客戶案 | 收錢替別人做的 | 一個客戶一個資料夾，一本 `筆記.md` |
| 02自己的招牌 | 你自己的帳號、個人品牌 | 自己的頻道、官網 |
| 03主力產品 | 你靠它賺錢的本事 | 有幾條拆幾個資料夾，例如剪接、腳本 |
| 04工具優化 | 讓大家做事更順的工具和流程 | 自動化、排程、小工具 |
| 05公司內部 | 公司自己的事 | 報價、方案、行政、財務 |
| 06對外上架 | 要公開、要賣的東西 | 課程、數位產品、入門包 |
| 07私人 | 跟工作無關的事 | 家人、興趣 |
| 封存 | 做完不再動的 | 不刪，找得回來 |

用不到的就不要建。

## 拿不準放哪
1. 問：**之後誰要一直養它？** 放它主要長大的地方。
2. 要公開或要賣的，一律放對外上架，不跟內部優化混。
3. 還是拿不準，問老闆一句。問的時候寫資料夾名字，不寫編號。

## 規矩
- 每個資料夾裡有 `筆記/`，放任務筆記本。客戶案一案一本 `<客戶>/筆記.md`。
- 資料夾名字用數字開頭。字數相同的中文資料夾會共用同一份記憶，數字開頭才分得開，順序也固定。
- 桌面 App 側邊欄的分區，名字跟資料夾一樣。
- 定了就少搬。搬資料夾會弄壞排程、自動檢查和對話記憶，要搬先查誰在用那個路徑。
